# 🔐 Sistema de Autenticação

Aplicação web desenvolvida em Python para gerenciamento de autenticação de usuários, controle de acesso e validação de credenciais.

O projeto implementa funcionalidades de login, autenticação e proteção de rotas utilizando backend em Flask.

---

## 🚀 Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Validação de credenciais
- Controle de sessão
- Proteção de rotas
- Estrutura backend organizada
- Gerenciamento de autenticação
- Processamento seguro de dados de login

---

## ⚙️ Tecnologias utilizadas

- Python 3
- Flask
- HTML
- CSS
- JavaScript

## 📦 Instalação

### Clonando o repositório

```bash
git clone https://github.com/caioalmeidasilvagamer-dev/autenticacao.git
```

Entre na pasta:

```bash
cd autenticacao
```

---

## 📥 Instalando dependências

### Windows CMD

```cmd
pip install flask
```

### Windows PowerShell

```powershell
pip install flask
```

### Linux

```bash
pip install flask
```

### macOS

```zsh
pip install flask
```

---

## ▶️ Executando a aplicação

### Windows CMD

```cmd
python app.py
```

### Windows PowerShell

```powershell
python app.py
```

### Linux

```bash
python3 app.py
```

### macOS

```zsh
python3 app.py
```
